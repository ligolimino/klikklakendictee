# Publiceren op GitHub Pages

## Eenmalig publiceren

1. Meld je aan op GitHub en maak een nieuwe repository, bijvoorbeeld `lws-letterlab`.
2. Kies **Public** en maak de repository aan.
3. Kies **Add file → Upload files**.
4. Upload de **inhoud** van deze map: `index.html`, `styles.css`, `app.js`, `data.js`, `.nojekyll`, de documentatie en de map `assets`.
5. Kies onderaan **Commit changes**.
6. Open **Settings → Pages**.
7. Kies bij **Build and deployment** voor **Deploy from a branch**.
8. Selecteer de branch `main`, de map `/ (root)` en kies **Save**.

Na enkele minuten verschijnt bovenaan dezelfde pagina het openbare adres. Dat lijkt op:

`https://gebruikersnaam.github.io/lws-letterlab/`

De gezamenlijke beheerpagina staat daarna op:

`https://gebruikersnaam.github.io/lws-letterlab/beheer/`

Open die pagina om afzonderlijke links voor dictee- en klik-klakoefeningen te maken.

## Insluiten in Genially

Gebruik in Genially de optie voor externe inhoud of een iframe en plak de openbare GitHub Pages-link. Geef het kader zoveel mogelijk van de beschikbare breedte en hoogte. Test zowel staand als liggend op een echte smartphone.

Als Genially de pagina niet rechtstreeks wil insluiten, gebruik dan een knop die dezelfde link in een nieuw tabblad opent. De cursist hoeft niet aan te melden.

## Een nieuwe versie plaatsen

1. Open de repository op GitHub.
2. Upload de gewijzigde bestanden met **Add file → Upload files**.
3. Laat GitHub bestanden met dezelfde naam vervangen.
4. Kies **Commit changes**.

De bestaande link blijft gelijk. GitHub Pages publiceert de nieuwe versie automatisch.

## Back-up en overdracht

- Bewaar altijd ook de volledige ZIP buiten GitHub.
- Gebruik voor de definitieve versie bij voorkeur een GitHub-organisatie van Ligo.
- Geef minstens twee medewerkers beheerdersrechten.
- Noteer repository, openbare link en herstelgegevens in de interne beheerhandleiding.
- Exporteer later ook de oefenreeksen en audio; gegevens die in deze proefversie lokaal in de browser zijn toegevoegd, staan nog niet automatisch in GitHub.

## Belangrijk voor deze proefversie

- De meegeleverde oefeningen, woordenbank, vormgeving en Andika-lettertype werken zelfstandig.
- Toevoegingen van een lesgever worden voorlopig alleen in de browser van dat toestel bewaard.
- Microfoonopnames vereisen een beveiligde `https`-verbinding; GitHub Pages biedt die.
- Browseruitspraak is voorlopig een noodoplossing. Gebruik eigen opnames voor fonetisch correcte losse klanken.
